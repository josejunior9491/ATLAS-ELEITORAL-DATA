# ATLAS-ELEITORAL-DATA
Dados eleitorais oficiais e arquivos historicos do ATLAS ELEITORAL

## Claude Desktop no SETUPTI — uso condicionado

Consulte [a orientação operacional](docs/CLAUDE_DESKTOP_SETUPTI.md) antes de utilizar os conectores locais do JJ-DEV neste projeto. O inventário `list_projects` não concede leitura de outros repositórios; `read_approved_file` continua restrito aos oito documentos autorizados **do JJ-DEV**. O uso do Claude Desktop não amplia permissões, substitui os gates próprios deste projeto ou autoriza escrita, merge e deploy. Configuração de acesso adicional requer aprovação e homologação específicas.

## Instruções obrigatórias para IAs

Antes de executar operações neste projeto, ler [`AGENTS.md`](AGENTS.md), incluindo o protocolo canônico de entrega do `.sh` no GitHub, relatório temporário no Drive, limpeza local após readback e limpeza remota após leitura da IA.
